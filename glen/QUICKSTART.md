# Быстрый старт 🚀

## Пошаговая инструкция по запуску

### Шаг 1: Установка PostgreSQL и Redis

**PostgreSQL:**
1. Скачайте с https://www.postgresql.org/download/windows/
2. Установите, запомните пароль пользователя postgres
3. Откройте pgAdmin или psql и создайте базу данных:

```sql
CREATE DATABASE buryatia_tourism;
```

**Redis (опционально):**
1. Скачайте с https://github.com/microsoftarchive/redis/releases
2. Запустите Redis сервер

### Шаг 2: Настройка .env файла

```bash
# В корневой папке проекта
copy .env.example .env
```

Откройте `.env` и измените:

```env
DB_PASSWORD=ваш_пароль_postgres
JWT_ACCESS_SECRET=любой_случайный_ключ_1
JWT_REFRESH_SECRET=любой_случайный_ключ_2
```

### Шаг 3: Миграции и seed данные

```bash
# Создание таблиц
npm run migrate

# Заполнение данными
npm run seed
```

### Шаг 4: Запуск приложения

```bash
npm run dev
```

### Шаг 5: Проверка работы

1. **Главный сайт:** http://localhost:3000
2. **Админ-панель:** http://localhost:3000/admin.html
   - Email: `admin@buryatia.ru`
   - Пароль: `admin123`

## 🐛 Решение проблем

### Ошибка подключения к базе данных
```
Error: connect ECONNREFUSED
```
**Решение:** Убедитесь, что PostgreSQL запущен и параметры в `.env` правильные

### Ошибка Redis
```
Redis Client Error
```
**Решение:** Приложение будет работать без Redis, просто медленнее. Или установите Redis.

### Порт уже используется
```
Error: listen EADDRINUSE: address already in use :::3000
```
**Решение:** Измените PORT в `.env` на другой (например, 3001)

### JWT ошибки
**Решение:** Убедитесь, что `JWT_ACCESS_SECRET` и `JWT_REFRESH_SECRET` установлены в `.env`

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте, что все шаги выполнены
2. Посмотрите консоль на ошибки
3. Убедитесь, что PostgreSQL запущен
4. Проверьте файл `.env`
